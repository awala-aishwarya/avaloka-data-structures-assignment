# Avaloka — Data Structures & Systems Design Assignment

## Overview
Python solutions for the AI / Multi-Agent Systems Intern take-home assignment at Avaloka (Guruvai Sciences).

## Problems solved
1. **LRU Cache:** Implements `get(key)` and `put(key, value)` using a hash map and doubly linked list, achieving average O(1) time for both operations.
2. **Event Scheduler:**
   - `can_attend_all(events)`: Checks whether events overlap.
   - `min_rooms_required(events)`: Calculates the minimum number of meeting rooms required using sorting and a min-heap.

## Requirements
- Python 3
- No external packages required; `heapq` is part of the Python standard library.

## How to run
```bash
python avaloka_assignment.py
```

The script runs basic tests and prints `All assignment tests passed.` when they succeed.
